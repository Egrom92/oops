# Конвертер раскладки для macOS

Напечатали «ghbdtn» вместо «привет»? Нажмите и отпустите **Ctrl+Option** — текст исправится, а раскладка переключится сама. Замена Punto Switcher без слежки за клавиатурой.

- **Есть выделение** → конвертируется выделенный текст.
- **Нет выделения** → конвертируется последнее слово перед курсором.
- Направление выбирается само: чего в тексте больше — латиницы или кириллицы.
- Раскладки: U.S. ↔ «Русская – ПК».
- Буфер обмена после конвертации возвращается как был.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/Egrom92/layout-converter/main/install.sh | bash
```

Установщик ставит [Hammerspoon](https://www.hammerspoon.org) (через Homebrew, если его нет), кладёт скрипт в `~/.hammerspoon/layout_converter.lua` и подключает его строкой в `~/.hammerspoon/init.lua`. Ваши собственные настройки Hammerspoon при этом не затираются.

Один раз выдайте доступ: Системные настройки → Конфиденциальность и безопасность → **Универсальный доступ** → Hammerspoon.

Удаление:

```bash
curl -fsSL https://raw.githubusercontent.com/Egrom92/layout-converter/main/uninstall.sh | bash
```

## Почему не Punto Switcher

Punto перехватывает каждое нажатие клавиши, и при нехватке памяти набор начинает подтормаживать. Этот скрипт обычные нажатия не видит: он слушает только модификаторы (Ctrl, Option, Shift, Cmd), а остальные клавиши отслеживает лишь пока зажаты Ctrl+Option, чтобы понять, что это не другое сочетание. Автоматического переключения на лету нет: только по вашему сочетанию.

## Как устроено

- Сочетание срабатывает, если Ctrl+Option нажали и отпустили меньше чем за секунду и в это время не нажимали другие клавиши или кнопки мыши.
- Выделение копируется через ⌘C, конвертируется и вставляется через ⌘V; потом буфер обмена восстанавливается.
- Последнее слово: ⌘⇧← выделяет начало строки, скрипт находит слово и выделяет только его. В терминалах (Terminal, iTerm2, Warp, Ghostty) это отключено: там ⌘⇧← работает иначе.
- macOS иногда отключает перехват событий: раз в 5 секунд скрипт проверяет это и включает обратно.

## Ограничения

- Только U.S. и «Русская – ПК». Другие раскладки (например, «Русская» без «ПК» или эстонская) нужно добавить в таблицу `KEYS` и в `RU_LAYOUT` / `EN_LAYOUT`.
- Работает там, где есть ⌘C/⌘V и обычное выделение текста.
