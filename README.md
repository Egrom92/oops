# Layout Converter

Напечатали «ghbdtn» вместо «привет»? Нажмите и отпустите **Ctrl+Option** — текст исправится, а раскладка переключится сама. Маленькое приложение для macOS в строке меню, замена Punto Switcher без слежки за клавиатурой.

- **Есть выделение** → конвертируется выделенный текст.
- **Нет выделения** → конвертируется последнее слово перед курсором.
- **Любые раскладки.** Соответствие клавиш берётся из самих раскладок macOS, поэтому работают все включённые: английская, русская (и «ПК», и обычная), украинская, эстонская, латышская, литовская, финская, шведская, норвежская, датская, исландская, немецкая, польская и другие. Например, «üjhjij», набранное на эстонской раскладке, превращается в «хорошо».
- **Направление выбирается само.** Исходная раскладка — та, на которой можно набрать буквы текста (при равенстве — текущая). Целевая — последняя использованная раскладка другого алфавита: кириллица ↔ латиница. Если вы переключаетесь между русской и эстонской, русский текст уйдёт в эстонскую, а если между русской и U.S. — в U.S.
- Буфер обмена после конвертации возвращается как был. Временный текст помечен так, чтобы менеджеры буфера обмена его не запоминали.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/Egrom92/layout-converter/main/install.sh | bash
```

Нужны macOS 13+ и бесплатные инструменты разработчика Apple: если их нет, установщик предложит поставить. Приложение собирается на вашем Mac и ставится в «Программы»; автозапуск при входе включается сам (выключить — в меню значка).

Один раз выдайте доступ: Системные настройки → Конфиденциальность и безопасность → **Универсальный доступ** → Layout Converter. Он нужен, чтобы заметить Ctrl+Option и нажать ⌘C / ⌘V за вас.

Если раньше стоял конвертер на Hammerspoon, установщик его выключит, чтобы сочетание не срабатывало дважды.

Удаление:

```bash
curl -fsSL https://raw.githubusercontent.com/Egrom92/layout-converter/main/uninstall.sh | bash
```

## Как устроено

- Обычные нажатия клавиш приложение не видит: оно слушает только модификаторы (Ctrl, Option, Shift, Cmd), а другие клавиши — лишь пока зажаты Ctrl+Option, чтобы отличить сочетание от Ctrl+Option+что-то. Сочетание срабатывает, если его нажали и отпустили быстрее чем за секунду.
- Выделение копируется через ⌘C, конвертируется и вставляется через ⌘V.
- Последнее слово: ⌘⇧← выделяет начало строки, приложение находит слово и выделяет только его. В терминалах (Terminal, iTerm2, Warp, Ghostty) это отключено, там работает только выделение.
- Проверка конвертации на настоящих раскладках: `swift run -c release LayoutCheck`.

## Ограничения

- Работает там, где есть ⌘C / ⌘V и обычное выделение текста.
- Конвертирует между раскладками разных алфавитов (кириллица ↔ латиница). Между двумя латинскими (U.S. ↔ эстонская) — только если других не включено.
